# Selected Design Studies

Independent concept portfolios for luxury textile, furniture, and architectural presentation.

- VELOUR: interactive Canvas material renderer with textures, colors, directional light, and motion controls.
- FORMA: SVG furniture configurator and a layered architectural atmosphere comparison.

The brands, products, and interiors are fictional design studies. These are not completed client commissions. Built with HTML, CSS, and JavaScript. Editorial imagery is AI-generated. These projects do not use Webflow or SPINE.

Open index.html through any static HTTP server. Both projects use relative links and can be hosted beneath a GitHub Pages project path.
